# ORNIX

### Bridging AI & Ethiopia's Growth

Ornix AI Solutions PLC is an Ethiopia-based technology organization focused on applying **Artificial Intelligence, healthcare technology, and digital innovation** to real-world challenges.

This repository contains the frontend implementation of the official Ornix website.

## Live Website

**https://ornix.com.et**

> **Intelligence for a Healthier Future.**

---

## About Ornix

Ornix works at the intersection of **Artificial Intelligence, healthcare, software engineering, and digital transformation**.

The website presents the organization's:

* AI capabilities
* Healthcare technology focus
* Digital solutions
* Research and innovation
* Strategic direction
* Services and areas of expertise
* Contact and engagement channels

The platform is designed to provide a clear digital presence for an organization building practical, locally relevant technology solutions.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

---

## Environment Configuration

Environment-specific values should be configured through environment variables.

Sensitive credentials and local environment files should never be committed to the repository.
